An Android [OpenStreetMap](https://www.openstreetmap.org/) Anti-Surveillance surveying application
built with **Jetpack Compose**
and
**MapLibre**.
The app is designed for adding points of interests to the OSM database easily.

## Features

### Counter Surveillance Measures

* Add camera nodes directly in app
* Give additional information for cameras
* Easily direction (`camera:direction`) editing
* `camera:mount` `camera:type` specification
* `surveillance`, `surveillance:type` and `surveillance:zone` specification
* NSI support for camera types

### Proxy

* Route your application network through proxy

### Easy to use

* StreetComplete or EveryDoor like ui
